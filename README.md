A high-performance, responsive single-page developer portfolio showcasing full-stack Java and React projects with fluid animations.

## Tech Stack

- **React 19** – UI library
- **Vite** – Next generation frontend tooling
- **Tailwind CSS 4** – Utility-first CSS styling
- **Framer Motion** – Physics-based animations & interactive gestures
- **AOS** – Animate On Scroll library
- **EmailJS** – Direct browser email delivery
- **WebGL** – Fluid splash cursor simulation

---

## Run Locally

Clone the repository and run the following commands:

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build
```

---

## Environment Variables

To enable the interactive contact form, create a `.env.local` file in the project root with the following variables:

- `VITE_EMAILJS_SERVICE_ID`
- `VITE_EMAILJS_TEMPLATE_ID`
- `VITE_EMAILJS_PUBLIC_KEY`

If these variables are not provided, the contact form automatically falls back to the visitor's default email client.
